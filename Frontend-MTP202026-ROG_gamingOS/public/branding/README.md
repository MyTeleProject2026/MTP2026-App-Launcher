# MTP2026 Branding

The MTP2026 Device OS uses the MYTELEPROJECT2026 visual identity supplied by the project owner.

The supplied artwork contains square and round app icons, horizontal and vertical logos, a cover/banner, a watermark and a social-media cover. The PWA icon has been converted into a native MTP2026 crown/`M` vector mark while the source artwork provenance is preserved in `brand-provenance.json`.

## Brand assets

- `icon-square.png` — 1024×1024 square app icon
- `icon-round.png` — 1024×1024 round app icon
- `logo-horizontal.png` — horizontal product logo
- `cover-banner.png` — cover/banner artwork
- `logo-vertical.png` — vertical/stacked logo
- `logo-mark.png` — standalone MTP2026 mark
- `watermark.png` — watermark variant
- `social-cover.png` — social-media cover

## Brand direction

- Black/deep navy technology background
- Gold crown and primary `M` mark
- Electric blue/cyan secondary accents
- Gold + blue MYTELEPROJECT2026 wordmark
- MTP2026 Device OS as the product identity

## OS identity

The operating system is named **MTP2026 Device OS**. It is an original MTP2026 platform and is not Apple iOS, Android, or Windows firmware.

## Product services

- VexaAccount — identity and device account
- VexaStore — application distribution and installation
- VexaEmail — future system application
- VexaTube — future system application
- VexaBrowser — system browser
- VexaCloud — cloud storage/sync service
- Vexa Passwords — credential manager
